# 项目业务约定（GD-SaiKen Fork）

## API 总则说明

- 主站 `/api/v1/*` 沿用 **WeKnora 上游** 信封与字段风格（非 `dev-standards` 中的 Nest `{ code, data, msg, message }` 模板）。
- **fork 增量**接口在 SDD 中单独立项；本期以 dsh-work 集成为准。

## dsh-work 集成（服务端）

| 操作 | 方法 | 路径 |
|------|------|------|
| 换票 | `POST` | `/api/v1/integrations/dsh-work/sessions` |
| 签发绑定登录 URL | `POST` | `/api/v1/integrations/dsh-work/bind-codes` |
| 兑现绑定码 | `POST` | `/api/v1/integrations/dsh-work/bind-codes/exchange` |

- 鉴权：`Authorization: Bearer <DSH_WORK_INTEGRATION_SECRET>`（未配置密钥时路由表现同未部署，404）。
- 绑定回调：`redirect_uri` 须在 `DSH_WORK_BIND_REDIRECT_ALLOWLIST` 内。
- 登录完成：`LoginResponse.bind_redirect_url`（JSON camelCase）供前端跳转。

详细错误码与正文见 [`docs/SDD/规格文档/26-10-29 dsh-work 知识库换票.md`](SDD/规格文档/26-10-29%20dsh-work%20知识库换票.md)。

## 资源命名

- 请求/响应 JSON：**camelCase**（与上游一致）；dsh-work 换票请求体字段按 SDD 使用 **snake_case**（`subject`、`ai_hub_user_id` 等）。
