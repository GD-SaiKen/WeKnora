# 对外统一 MCP 按用户登录 实现计划

> **面向实现者：** 按任务顺序做。每个任务先写失败测试，再写让该测试通过的最少代码，用该任务里的 `go test` 或前端测试命令确认。用 `- [ ]` 跟踪。不要并行改 `/mcp/:endpoint_id` 的令牌语义。
>
> **规格：** [对外统一 MCP 按用户登录](../规格文档/26-10-24%20对外统一MCP按用户登录.md)
>
> **目标：** 增加固定入口 `/mcp`，外部 Agent 用授权码和 PKCE 让用户以自己的账号登录，工具调用按该用户在所选空间的权限执行。
>
> **架构：** 新入口与现有端点入口分开认证。`/mcp/:endpoint_id` 继续只认 `mcp_` 令牌和合成用户。`/mcp` 只认受众为 `weknora-mcp` 的用户 access token，并把真实用户、成员角色、空间级工具天花板放进请求上下文。工具目录仍是现有 `mcpserver.Server` 的一份清单；过滤和限流按「天花板 ∩ 用户权限」以及「用户 + 空间」执行。网页 JWT（无此受众）不能调用 `/mcp`，MCP access token 不能调用普通 `/api/v1`。
>
> **技术栈：** Go、Gin、现有 JWT HS256（`getJwtSecret`）、PostgreSQL 迁移 `versioned` 与 SQLite 迁移、Vue 3 集成设置页。
>
> **新建文件目录：** 本仓库后端测试放在被测包的 `*_test.go`，不使用 `src/__test__/`。前端沿用 `frontend/src/views/integrations/` 与 `frontend/src/api/` 的现有布局；新测试写在同目录已有 `*.test.ts` 旁，不另建 `__test__`。
>
> **不改：**
> - `POST/GET/DELETE /mcp/:endpoint_id` 的路径、`mcp_` 令牌校验、合成用户 `mcp-<端点 id>`
> - 出站「工具箱 → MCP 服务」的 OAuth（`internal/mcp/oauth_*.go`）
> - 嵌入聊天、IM 回调
> - 网页登录账号体系（不新增第二套用户表）
> - dsh-work

```go
func TestPKCERejectsPlainAndWrongVerifier(t *testing.T) {
    if err := sharedmcp.VerifyS256("not-s256", "abc"); err == nil {

    }
    verifier := "abcdefghijklmnopqrstuvwxyzABCDEFGHIJKLMNOPQRSTUVWXYZ0123456789-._~"

    if err := sharedmcp.VerifyS256(challenge, verifier); err != nil {

    }
    if err := sharedmcp.VerifyS256(challenge, verifier+"x"); err == nil {
        t.Fatal("wrong verifier must fail")
    }

func TestMCPAccessTokenIsNotAWebToken(t *testing.T) {
    access, refresh, err := sharedmcp.IssueTokenPair(sharedmcp.TokenInput{
        UserID: "user-1", TenantID: 7, ClientID: "client-1", GrantID: "grant-1",
        Now: time.Unix(1_700_000_000, 0),
    }, "test-secret")
    if err != nil {
        t.Fatal(err)
    }
    claims, err := sharedmcp.ParseAccessToken(access, "test-secret", time.Unix(1_700_000_000, 0))
    if err != nil {
        t.Fatal(err)
    }
    if claims.Audience != "weknora-mcp" || claims.UserID != "user-1" || claims.TenantID != 7 {
        t.Fatalf("claims %+v", claims)
    }
    if claims.ExpiresAt.Sub(claims.IssuedAt) != time.Hour {
        t.Fatalf("access ttl %s", claims.ExpiresAt.Sub(claims.IssuedAt))
    }
    rc, err := sharedmcp.ParseRefreshToken(refresh, "test-secret", time.Unix(1_700_000_000, 0))
    if err != nil || rc.GrantID != "grant-1" {
        t.Fatalf("refresh %+v %v", rc, err)
    }
}
```

运行：`go test ./internal/sharedmcp/ -count=1`

预期：FAIL，包或函数不存在。

- [ ] **步骤 2：实现**

`VerifyS256` 只接受方法缺省时由调用方传入的 challenge 与 verifier 的 SHA-256 base64url（无填充）比较。`IssueTokenPair` 的 access claims 固定为：

- `aud`: `weknora-mcp`
- `type`: `mcp_access`
- `user_id`、`tenant_id`、`client_id`、`grant_id`
- `exp` = `iat` + 1 小时

refresh claims：`type=mcp_refresh`，`grant_id`，`exp` = `iat` + 30 天。签名用调用方传入的 secret，算法只接受 HS256。解析时受众或 type 不对则返回错误。

预期：PASS
